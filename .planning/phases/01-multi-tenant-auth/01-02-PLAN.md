<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → magic-link/confirm routes | Untrusted email + token_hash cross here |
| Google → callback route | OAuth code + state cross here (cross-domain redirect) |
| browser → setup/sheet route | Untrusted sheet_id + default_offer cross here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Spoofing | Google OAuth callback | mitigate | `state` param compared to httpOnly sameSite=lax cookie; mismatch rejected (Pitfall 5) |
| T-01-07 | Information Disclosure | magic-link email enumeration | mitigate | Return `{ok:true}` regardless of email existence + `shouldCreateUser:false` |
| T-01-08 | Spoofing | magic-link token reuse | mitigate | `verifyOtp` invalidates the one-time token on use (Supabase) |
| T-01-09 | Information Disclosure | refresh token at rest | mitigate | `encrypt()` before upsert into outreach_tokens; never stored plaintext (D-06) |
| T-01-10 | Tampering | default_offer input | mitigate | Server validates against the three enum values or null before upsert |
| T-01-11 | Elevation of Privilege | setup/sheet write | mitigate | Session-bound anon client only; RLS user_id=auth.uid() (Pitfall 6) |
</threat_model>
