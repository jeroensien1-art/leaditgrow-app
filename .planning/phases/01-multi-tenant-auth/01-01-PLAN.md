| browser → middleware | Untrusted requests to /outreach/* and /api/outreach/* cross here; JWT validated server-side |
| route handler → Supabase | Encrypted token + user rows cross here; RLS enforces row isolation |
| app → npm registry | One new package (@supabase/ssr) installed here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | /outreach/* and /api/outreach/* | mitigate | Middleware getClaims() JWT check; pages redirect, APIs return 401 (D-11) |
| T-01-02 | Information Disclosure | outreach_tokens rows | mitigate | AES-256-GCM encryption before insert + RLS user_id=auth.uid() (D-06, D-14) |
| T-01-03 | Tampering | encrypted_token value | mitigate | GCM auth tag verified on decrypt; altered ciphertext throws |
| T-01-04 | Information Disclosure | leads / diagnostics protected tables | mitigate | Migration adds NEW tables only; no DROP/TRUNCATE/ALTER on protected tables |
| T-01-05 | Elevation of Privilege | SUPABASE_SERVICE_KEY (admin client) | mitigate | createAdminClient used only in server route handlers, never client components |
| T-01-SC | Tampering | npm install @supabase/ssr | accept | Package is [Approved] in RESEARCH Legitimacy Audit (official @supabase org); single trusted package, no checkpoint required |
</threat_model>
